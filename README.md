# odin-recipes

This project is a practice repository created while learning Git and GitHub through The Odin Project Foundations course.

## About

The purpose of this project is to learn the basic Git workflow, including creating repositories, cloning repositories, making commits, and pushing changes to GitHub.

## Skills Demonstrated

By completing this project, I demonstrated the ability to:

- Create and manage a Git repository
- Connect a local repository to GitHub
- Clone repositories using SSH
- Track changes using Git
- Create meaningful commits
- Push code to GitHub

## Self Reflection

Through this project, I learned how Git helps developers track their work and collaborate with others. I became familiar with the basic workflow used by professional developers:

1. Make changes
2. Check status
3. Stage changes
4. Commit changes
5. Push changes to GitHub
